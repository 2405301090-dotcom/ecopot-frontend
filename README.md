# EcoPot – Grow Green, Live Clean

A responsive React + Vite landing page for a fictional eco-friendly plant pot brand.

## Run locally
```bash
npm install
npm run dev      # development server
npm run build    # production build into /dist
npm run preview  # preview the production build
```

## Deploy
Push to GitHub, import the repo on vercel.com (Framework: Vite, build `npm run build`, output `dist`).
